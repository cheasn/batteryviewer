# v1.0.0 — 首次公开发布

Windows x64 的 2.4G 外设电量小工具，当前面向迈从 K7 Ultra 鼠标与 ROG Strix Scope RX TKL Wireless Deluxe 键盘。

## 包含功能

- 右下角鼠标、键盘绿色圆环电量图标，悬停查看精确读数和时间。
- 可拖动的双卡片简洁面板；左键托盘刷新单台，右键打开面板并刷新两台。
- 跨重启保留上次成功电量；断链、超时或失败时标注旧读数，成功后替换。
- 每天定时、自定义间隔和活动 / 查看刷新，支持开机自启与单实例。
- `--debug` HID 调试与协议标定，按需辅助进程及退出清理。
- 无运行日志文件，只保存设置和最新两条电量快照。

## 下载

附件：`PeripheralBattery-v1.0.0-win-x64.zip`。解压整个目录并运行 `PeripheralBattery.exe`，无需另外安装 .NET。GitHub 的 `Source code` 附件为源码，不是运行包。

## 验证与限制

- Windows 10 22H2 x64 已实机验证；Windows 11 x64 尚待验证。
- K7 实测电量与官方软件一致；ROG HID 读数已验证，官方软件对照待完成。
- 50 项自动回归及两枚通知区图标的真实 Shell 注册检查通过。
- 其他固件、接收器、充电切换、8K 输入、高 DPI / 多屏等仍需进一步实测。

详细使用方法见仓库 README，协议与复验结果见 `docs/`。
